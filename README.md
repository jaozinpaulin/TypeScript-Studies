# TypeScript Studies

Repositório dedicado aos meus estudos de TypeScript.

O objetivo deste projeto é consolidar os principais conceitos da linguagem por meio de exemplos práticos e exercícios, criando uma base sólida para desenvolvimento com React, Next.js e Node.js.

## Conteúdo

- Tipos Primitivos
- Arrays
- Objetos
- Funções
- Type Alias
- Interfaces
- Propriedades Opcionais
- Union Types
- Arrays de Objetos
- Generics (em andamento)

## Tecnologias

- TypeScript
- Node.js
